# Asklane — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Citizen / applicant

- As a citizen, I want a clear answer to a routine question with a link to the official source, so that I do not wait on hold for information already on the website.
- As an applicant with limited English, I want to complete a benefits form in my language with human-checked translation for critical clauses, so that I do not sign something I misunderstand.
- As a digitally excluded citizen, I want an assisted channel (phone agent or in-person kiosk) that sees the same journey state, so that I am not forced onto a chatbot-only path.

### Contact-centre agent

- As an agent, I want routine password and FAQ volume deflected before it reaches my queue, so that I can spend time on time-sensitive and complex cases.
- As an agent, I want ai-drafted reply suggestions with cited knowledge articles, so that I respond faster without inventing policy.
- As an agent, I want to escalate a bot conversation into my queue with full transcript and identity state, so that the citizen does not repeat themselves.

### Service owner / knowledge editor

- As a service owner, I want to publish and retire knowledge versions tied to policy effective dates, so that the bot never answers from superseded rules.
- As a service owner, I want to see which journeys fail statutory clocks, so that I fix process design rather than add more bot scripts.

### Privacy, FOI, and compliance officer

- As a compliance officer, I want every adverse-decision attempt blocked and logged when no human approver is assigned, so that we do not create unlawful automated determinations.
- As an FOI officer, I want exportable interaction records with retention labels, so that we can respond to access requests without reconstructing chat logs from vendor portals.

### Platform administrator

- As a platform administrator, I want to configure legal gateways and receiving offices for cross-agency routing, so that misdirected petitions do not disappear into the wrong silo.
- As a platform administrator, I want accessibility and language coverage reports per channel, so that we can evidence obligations to auditors and advocates.
- As a citizen (exception path), I want to challenge an incorrect bot answer and force human review, so that a wrong deflection does not become a denied service.
